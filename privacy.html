Privacy Policy

Last updated: November 10, 2026

StellaArtBoard is a private, non-commercial tool used only by its owner. It reads the owner's own Pinterest boards, read-only, and keeps everything on the owner's own computer. Nothing is shared, sold, or sent anywhere.

WHO
The owner only
ACCESS
Read-only
STORED
Owner's computer only

1. What the app accesses

  • Only the owner's own Pinterest account, with read-only permissions: boards:read and pins:read.
  • It reads the owner's boards and pins and downloads the images the owner saved, for private drawing-style study.

2. What the app never does

  • It does not post, edit, or delete anything on Pinterest.
  • It does not access any other user's data.
  • It does not share, sell, republish, or transfer any data or images. Downloaded images are never shown on this website.
  • It does not use data for advertising, profiling, or training any AI model.

3. Storage and security

  • Downloaded images and access tokens are stored only on the owner's own computer.
  • Access tokens are kept in a private local folder and are never shared or displayed.
  • The owner can revoke access at any time in Pinterest settings and delete the local files at any time.

4. This website

This website uses no cookies, no analytics, no trackers and no third-party fonts or scripts. It only shows drawings we made ourselves.

5. Third parties

No data is sent to any third party.

6. Changes

If this policy changes, this page will be updated and the date above will change.
